# InventoryOS

BOLDNEST InventoryOS is an AI-powered, full-stack inventory management system built with Java (Spring Boot) and React, designed to streamline stock control, supply chain workflows, and intelligent business operations.

Core Capabilities:

Role-Based Access Control: Multi-tier account management where Owners create sub-accounts and assign granular permissions for Managers and staff.

Inventory & SKU Tracking: Centralized product catalog management with real-time stock quantities, pricing, and automated low-stock alerts.

Procurement & Automated Billing: End-to-end supplier purchase orders, stock receiving workflows, and customer invoicing with automatic, transactional stock deductions.

QR Code Lifecycle Tracking: Automated QR code generation (via ZXing) and instant scanning to inspect complete product histories, purchase records, and billing transactions.

Real-Time Analytics Dashboard: Visual summaries covering total inventory valuation, sales metrics, purchase expenses, and stock turnover.

Open-Source Agentic AI: Local LLM integration (via Ollama) providing automated reorder recommendations, stock anomaly detection, and a conversational assistant capable of querying live inventory data.
